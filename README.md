# Evidence of Labs

A technical repository documenting hands-on cybersecurity labs, practical exercises, and key learnings across various security domains.

## Areas of Focus

- Web Application Security
- API Security
- Network Security
- Vulnerability Assessment and Penetration Testing (VAPT)
- Red Teaming

## Repository Structure

Each lab is maintained in a dedicated directory containing technical documentation, practical observations, relevant screenshots, and key takeaways.

## Objective

To strengthen practical cybersecurity skills through structured lab exercises, document technical findings, and build a verifiable record of continuous learning.

## Updates

This repository is updated as new labs are completed and additional concepts and techniques are explored.
